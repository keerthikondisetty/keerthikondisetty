I keep payments platforms up. Around a million API calls a day on EKS, a 99.9% SLO, and a domain where a long outage turns into a compliance conversation.

Most of my work is the part that makes incidents rarer and shorter. Terraform modules that took environment provisioning from days to under an hour. Shared pipeline libraries that cut deployments from half a day of babysitting to thirty minutes. Better SLIs and honest postmortems that brought MTTR down by about a third. Rightsizing and Spot that took 20% off an AWS bill.

Regulated work means least-privilege IAM, Vault-managed secrets and NetworkPolicies have to be right before the audit rather than after it.

I learned most of this on call, at hours I don't recommend.

## Repos worth a look

Things I built to try ideas that production is a bad place to try.

[**eks-gitops-platform**](https://github.com/keerthikondisetty/eks-gitops-platform) — EKS where the whole cluster state lives in one Git repo. Argo CD app-of-apps, spot-first autoscaling, admission policy, and canaries that promote or roll back on live Prometheus queries.

[**aws-platform-foundation**](https://github.com/keerthikondisetty/aws-platform-foundation) — a multi-account AWS landing zone in code. Organizations, SCPs, centralized logging, a transit gateway hub, and CI that authenticates by OIDC so no static keys sit in a repo.

[**idp-golden-paths**](https://github.com/keerthikondisetty/idp-golden-paths) — self-service scaffolding, so a new service is a form rather than three tickets and a week of waiting.
